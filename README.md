## Features
- **Branding**: Modern dark cyberpunk neon glassmorphism UI with Web Audio API sound synthesizer.
- **Participant HUD**: Live score, stage progress bar, clue cards, and hint penalty tracker.
- **Optical QR Scanner**: Real-time camera scanner using `html5-qrcode` with reticle laser, plus manual code entry and simulation shortcuts.
- **5 Non-Trivial Puzzle Engines**:
  1. Caesar Shift Cryptogram (`SECURE_CODE`)
  2. 8-Bit Bus Hexadecimal Logic Checksum (`EF`)
  3. Signal Audio Morse Code Synthesizer (`SOS CAFE`)
  4. Central Archives Quadratic Root Solver (`5`)
  5. Master Vault Override Synthesis Key (`SES5VICTORY`)
- **Anti-Cheat Sequence Lock**: Prohibits stage skipping. Scanning ahead flags a security breach.
- **Organizer HQ**: Real-time audit logs, printable QR station badge generator, and live broadcast messaging.
- **Evaluation Suite**: 1-click test suite for judges to evaluate valid steps, sequence breaches, and full speedruns.
